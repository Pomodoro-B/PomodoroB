## About

Pomodoro/B is a lightweight Pomodoro timer built for focused work.

It keeps the experience simple: start a session, focus on your work, take a break, and repeat.

The application is designed to stay out of the way while you work, with a minimal interface and native experiences across supported platforms.

## Features

- Pomodoro focus sessions
- Short and long breaks
- Pause and resume
- Menu bar access on macOS
- Progress indication
- Lightweight background operation
- Minimal interface
- Native platform experiences

More features will be introduced as development continues.
